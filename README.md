# YAMEEN (يمين)

أداة مفتوحة المصدر لمساعدة المستخدمين على قراءة وضبط اتجاه النصوص العربية في برامج المحادثة والذكاء الاصطناعي على أنظمة ويندوز.

---

### المشاكل التي تعالجها الأداة:
- انقلاب ترتيب الأقواس وعلامات الترقيم في الجمل العربية.
- تداخل الكلمات الإنجليزية والأكواد مع النصوص العربية.
- قراءة الردود بسهولة عبر واجهة كلاسيكية داكنة ومريحة للعين بخط كايرو.

---

### الميزات الأساسية:
1. **كشف التطبيقات النشطة:** يقرأ العمليات المفتوحة بالنظام مثل محررات الأكواد ومتصفحات الويب ونوافذ المحادثة.
2. **محاذاة مباشرة:** تعديل اتجاه النوافذ الداعمة فوراً لليمين (RTL).
3. **قارئ نصوص مباشر:** صندوق قراءة بخط عربي منسق مع أزرار للتحكم بحجم الخط والنسخ السريع.
4. **معالجة الحافظة:** تنسيق النصوص المنسوخة لضمان بقاء الأقواس سليمة عند اللصق في تطبيقات أخرى.

---

### طريقة التشغيل:
```bash
pip install -r requirements.txt
python main.py
```

كما يتوفر ملف تنفيذي جاهز يعمل مباشرة بدون متطلبات إضافية داخل مجلد `dist`.

---

### الخصوصية والأمان:
البرنامج يعمل بالكامل على الذاكرة المحلية للجهاز بدون أي اتصال خارجي أو فتح لمنافذ شبكة، وهو آمن للاستخدام الشخصي والمكتبي.
